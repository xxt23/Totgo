# Totgo · 把注意力，放回此刻。

**Totgo** 是一款由 **Tot** 独立制作的纯单机专注力训练与正念桌面软件。  
界面采用纸白与墨黑双主题极简设计，不联网、无打扰，专注于日常视觉追踪、抗干扰反应与呼吸平复。

---

## 核心板块

### 01 / 多目标视觉追踪 (MOT)
记忆初始高亮的目标小球，在多球平滑位移与碰撞后准确找出它们。训练动态视觉持续追踪与空间注意力分配。

### 02 / 动态舒尔特方格
按升序依次寻找到打乱排列的数字网格。支持经典的静态模式与每次点击后平滑移位洗牌的动态进阶模式。

### 03 / 色词判断 (Stroop)
当文字的字面含义与实际颜色发生冲突时，快速辨别文字真正的颜色。支持键盘 `A` / `D` 键快捷二选一，锻炼反应抑制与抗干扰能力。

### 04 / 潮汐呼吸
内置「潮汐绵长」、「方盒均衡」与「深度宁静」三种呼吸节律。跟随四层同心圆环的舒展与收拢，平复思绪，收回散落的注意力。

---

## 软件特性

- **真实训练计时**：仅在实际训练关卡内记录时间，精确统计「今日有效训练时长」与「历史累计训练时长」。
- **随时暂歇与中断**：训练途中按下 `空格键` 或 `Esc` 即可进入暂歇状态；支持随时提前结束并归档当前进度。
- **纯本地数据档案**：自动记录各板块最佳成绩与近期训练日志，支持一键导出与导入 `.json` 本地备份文件。
- **双主题切换**：内置温润「纸白」与静谧「墨黑」两套低饱和度禅意配色，保护视力。

## 下载与运行（Windows）

1. 点击本页面右侧的 **[Releases]** 进入发行版下载页面。
2. 下载最新版本的 **`Totgo-v1.0-portable.exe`** 单文件免安装程序。
3. 下载后直接双击即可运行，无需安装任何额外组件，全程离线可用。

> **温馨提示**：本软件为个人独立开发作品，未配置商业数字签名。首次在 Windows 系统双击运行时，若弹出蓝色的系统保护提示框，请点击 **「更多信息」** → **「仍要运行」** 即可正常打开。
